# v3.1 visual audit checklist

What has already been checked, and what still needs a browser.

The static checks below run on the real build. Everything marked **BROWSER**
could not be verified in the environment this work was done in, because
Chromium could not be installed there. Rendering was done with WeasyPrint, which
is faithful on colour, type, rule-work and box widths but does not lay out CSS
grid, `object-fit` or JavaScript-driven state the way Chrome does.

Run the automated pass first:

    npm run build && npm run verify && npm run audit

## 3. Per-page browser review

Do each page at **1440, 1180, 1024, 768, 720, 430, 390 and 320px**.

### Every page

- [ ] **BROWSER** No horizontal scrollbar at 320px.
- [ ] **BROWSER** Header does not use ink. Navigation is legible; the current
      item is marked by a rule and weight, not by colour alone.
- [ ] **BROWSER** Below 900px the navigation collapses to the Menu disclosure;
      Escape closes it and returns focus to the toggle.
- [ ] **BROWSER** With JavaScript disabled, the full navigation is visible and
      no enlarge control is shown.
- [ ] Footer is on paper, opens with the four-colour spine and a strong rule.
- [ ] Skip link appears on first Tab and lands on `main`.
- [ ] **BROWSER** Every focusable element shows a 3px brass ring at 3px offset,
      and nothing is obscured by the sticky header.
- [ ] Text reflows without loss at 200% zoom and at 400% (SC 1.4.10).
- [ ] No brass-coloured text below 24px anywhere. Search the built CSS for
      `color: var(--brass)` outside `tokens.css`: it should return nothing.

### Homepage

- [ ] Exactly two ink bands, the opening and the close, with nothing dark
      between them and a paper footer beneath.
- [ ] Display type tops out at 74px, not 99px.
- [ ] **BROWSER** Proof strip runs four-up above 1000px, two-up above 640px.
- [ ] **BROWSER** The lead project card image crops top-centred at 16:10 and
      does not exceed 620px.
- [ ] The four-layer model shows icon, numeral, name and colour rule for each
      layer. Cover the colour: the meaning must survive.
- [ ] The portrait sits at 300px on a hairline, with no plate.
- [ ] One brass gesture in the "how to buy" block, and only one.
- [ ] Primary button is `#8C5E1C` with white; hover `#6F4711`; active `#5C3A0E`.

### Work index

- [ ] Three tiers, distinguished by scale and position, not by badges.
- [ ] **BROWSER** Every card cover crops top-centred at 16:10, capped at 560px.
- [ ] The evidence panel is on plate, not ink, and its numerals read clearly.
- [ ] The gap panel is a hatched plate and states what is missing.

### Every case study

- [ ] The rhythm is: shortened ink introduction, plate metadata strip, primary
      evidence on paper, "In 60 seconds" on raised paper, narrative, evidence,
      decisions, at most one further ink band, outcomes, next project on paper,
      contact on paper.
- [ ] The title is about 43px maximum, Demi not Bold, and does not overpower
      the evidence beneath it.
- [ ] The metadata strip is on plate, not inside the ink band, and its labels
      are secondary text, not tertiary.
- [ ] The primary figure is 800px, sits on paper, and does not touch a dark
      band. Corner registration marks are present on it and on no other figure.
- [ ] Exactly one primary figure. Not two.
- [ ] Every figure aligns to the left edge of the reading column. Nothing is
      centred.
- [ ] Every caption is 58ch, regardless of how wide its image is.
- [ ] No two monumental blocks in sequence: an ink band, a figure 800px or
      wider, or a panel taller than a viewport.
- [ ] No run of three or more full interface overviews.
- [ ] Evidence labels sit above the mount on a hairline, carrying the index
      numeral and the area.
- [ ] Interface screenshots use a bare hairline mount. Artefacts, details,
      pairs and phone screens use a plate. Photography uses neither.
- [ ] Plate padding is 20px, or 32px on plate-deep for transparent artefacts.
      Nothing is at v3's 34px.
- [ ] **BROWSER** Every `expandable` figure has an enlarge control, its caption
      says enlargement is needed, the dialog traps focus, Escape closes it,
      focus returns to the trigger, and the image is not enlarged past its
      native width.
- [ ] Next project and contact blocks are on paper, not ink.
- [ ] Below 720px: figures go full column, the shared left edge holds, and
      primary, supporting and detail figures still feel ranked. They should not
      collapse into an even stack.
- [ ] Phone pairs stay near physical scale, 230px on mobile, with no device
      mock-up, bezel or fake shadow.

### CASA programme and subprojects

- [ ] The programme rail sits on paper below the metadata strip.
- [ ] The programme map and subproject cards are on paper.
- [ ] AviationWorx carries placeholders only. No CLASS screen has been borrowed.

### Practice

- [ ] The engagement list is on paper, not ink.
- [ ] **BROWSER** Above 900px the layer tabs behave as an ARIA tab set: arrow
      keys move, Home and End jump, Enter and Space activate, the panel is
      focusable.
- [ ] Below 900px and with no JavaScript, every panel is shown and the tablist
      is hidden.
- [ ] Each tab shows icon, numeral, name and colour.

### About

- [ ] Exactly one ink band, the "how I work" block.
- [ ] The history list uses `--rule` between entries and `--rule-strong` under
      the section title.

### Contact

- [ ] No ink anywhere.
- [ ] **BROWSER** Form errors show a border change, a text message and an error
      summary, never colour alone. Every field has a visible label. The error
      summary links move focus to the field.
- [ ] Inputs are at least 48px tall with 16px text, so iOS does not zoom.

### Privacy

- [ ] The notice uses the semantic error tokens, not one-off hexes.

## 4. Regression checks against v3

Open v3 and v3.1 side by side.

- [ ] The same site is recognisable. Wordmark, architecture, navigation, page
      order, tone and content are unchanged.
- [ ] No page has been added or removed. Both build 21 pages.
- [ ] Every case-study narrative reads exactly as it did.
- [ ] No Signal colours anywhere. No orange, no bright teal, no indigo.
- [ ] The hierarchy is better: the argument leads and the evidence supports.
- [ ] Images no longer dominate. The default figure is 660px, not 982px.
- [ ] Dark is punctuation. Compare any case study: ink drops from roughly 20 to
      24 per cent to roughly 4 to 6 per cent.
- [ ] Brass text is accessible everywhere it appears.
- [ ] Mobile hierarchy survives.
