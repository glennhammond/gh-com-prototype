# v3.1 token record

The single source of truth is `src/styles/tokens.css`. This document states
what each token is for, what it must not be used for, and the contrast figure
behind it.

Every contrast figure below is computed, not estimated, and is re-computed on
every build by `scripts/audit.mjs`. Surface separation is stated as a CIE L*
delta, because a contrast ratio is the wrong instrument for judging whether two
adjacent pale surfaces read as different.

---

## 1. Surfaces

| Token | Value | L* | Use | Do not use for |
|---|---|---|---|---|
| `--paper` | `#F4F1E9` | 95.2 | The primary ground. Target 68% of page area | |
| `--paper-raised` | `#FCFAF5` | 98.3 | Panels that lift off the page: "In 60 seconds", key decisions, engagement notes. Target 12% | Full-width bands on every page. That is what made the footer and the Practice list too heavy in the first pass |
| `--plate` | `#E7E1D3` | 89.7 | Image mounts, the case-study metadata strip, the portfolio evidence panel. Target 8% | |
| `--plate-deep` | `#DED7C5` | 86.0 | Transparent artefacts and icon sheets, at 32px padding | **Any text or mark.** Brass measures 2.98:1 on it and brass-ink 4.38:1. Both fail |
| `--ink` | `#15191E` | 8.6 | The dark ground. Target 10% | Headers, navigation, metadata strips, image mounts, next-project blocks, contact blocks, routine content panels, most portfolio cards, the footer |
| `--ink-raised` | `#20262D` | 14.9 | Panels sitting on an ink band | |

`--plate` sits **5.53 ΔL\*** from paper. v3's `#EEEBE1` sat at 2.09, which is at
the limit of perception for large flat areas, so the plate read as a printing
error rather than as a mount. `--ink-raised` sits 6.31 ΔL* from the band,
against v3's 4.94.

### Where ink is permitted

The homepage opening, the homepage close, the case-study introduction, one
argument or decision band per case study, and the single argument band on the
About page. Nowhere else. Two ink bands per page is the ceiling, and no two
monumental blocks may appear in sequence.

**Dark is punctuation. If a page reads as dark, the balance has slipped.**

`--text-tertiary` is **forbidden on plate.** This was a real failure caught
during implementation: the case-study metadata strip moved onto plate and took
its tertiary labels with it. It now uses `--text-secondary`.

`--text-tertiary` is never used for prose, on any surface.

## 3. Brass, in three parts

This is the correction that fixes a live WCAG 1.4.3 failure in v3, which set
10.5px mono chips in `#A67A2E` on paper at 3.42:1.

| Token | Value | Contrast | Use | Do not use for |
|---|---|---|---|---|
| `--brass` | `#A66F22` | 3.78 paper, 4.09 raised, 3.28 plate | Rules, focus indicators, section marks, the 3px gesture, corner registration marks, list bullets, underlines, layer 01 swatch | **Any text, at any size.** It fails 4.5:1 on all three pale surfaces |
| `--brass-ink` | `#855619` | 5.57 paper, 6.02 raised, 4.82 plate, 5.12 on brass-tint | Every piece of brass-coloured text: eyebrows, evidence labels, index numerals, chips, tags | Anything on plate-deep (4.38, fails) |
| `--brass-light` | `#D0A45B` | 7.69 on ink | Brass on an ink band, text or mark. Focus on ink | Pale surfaces |
| `--brass-tint` | `#F1E7D4` | L* 92.0 | Chip and callout grounds | |

`#855619` was chosen because one value clears 4.5:1 on paper, raised paper
**and** the plate. `#8C5E1C` measured 4.32 on the plate and would have needed a
third token.

### The primary action

| Token | Value | White on it | Boundary on paper |
|---|---|---:|---:|
| `--action-primary` | `#8C5E1C` | 5.63 | 4.98 |
| `--action-hover` | `#6F4711` | 8.12 | |
| `--action-active` | `#5C3A0E` | 10.16 | |
| `--action-foreground` | `#FFFFFF` | | |

On an ink band the action colour alone sits at 2.4:1 against the ground, below
SC 1.4.11 for a component boundary, so `.on-ink .btn--primary` takes a
`--brass-light` border at 7.69:1. The action colour itself does not change.

## 4. Mineral

The supporting colour. Cool enough to counterweight a warm page, muted enough
not to compete with brass, and already latent in the system because v3's
Layer 02 was a green.

| Token | Value | Contrast | Use |
|---|---|---:|---|
| `--mineral` | `#46665B` | 5.62 on paper | Layer 02, non-text marks |
| `--mineral-ink` | `#3A5A4F` | 6.75 paper, 7.31 raised | Link hover, card hover, small mineral text |
| `--mineral-light` | `#7FA396` | 6.37 on ink | Mineral on an ink band |
| `--mineral-tint` | `#E3EAE6` | L* 92.1 | Layer 02 chip ground |

Target 0.5% of page area. Mineral is a counterweight, not a second accent.

## 9. Links

| Token | Value |
|---|---|

| `--link-underline` | `--brass` |
| `--link-hover` | `--mineral-ink` |

## 10. The four layers

| Layer | Mark | Text | Tint | Icon |
|---|---|---|---|---|
| 01 Experience | `#A66F22` | `#855619` | `#F1E7D4` | `layer-experience` |
| 02 Content | `#46665B` | `#3A5A4F` | `#E3EAE6` | `layer-content` |
| 03 Platform | `#526171` | `#435264` | `#E4E7EB` | `layer-platform` |
| 04 Operations | `#15191E` | `#15191E` | `#E5E5E4` | `layer-operations` |

On an ink band Layer 04 lifts to `--layer-4-on-ink` `#7D8894`, at 4.89:1, for
swatch and rule use only.

Three devices present the four as one family: the **spine** (four rules in
sequence), **chips** that are all legible as text, and **icon plus numeral plus
name plus colour**. Colour is never the only signal. The numeral, the name and
the icon always travel with the swatch.

## 14. Shape and motion

| Token | Value | Note |
|---|---|---|
| `--radius` | 2px | No corner radius above 2px anywhere. No consumer rounding |
| `--motion-state` | 140ms | Hover, focus and small state changes |
| `--motion-entrance` | 600ms | One entrance site-wide |
| `--ease` | `cubic-bezier(0.2, 0, 0.2, 1)` | |

Both motion tokens drop to 1ms under `prefers-reduced-motion: reduce`, and
`global.css` also clamps every animation and transition.

Excluded by the system, and absent from the built CSS: gradients other than the
placeholder hatch, glassmorphism, blur, drop shadows, gold gradients, serif
small caps and letterspaced display headings.
