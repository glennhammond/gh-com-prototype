## Accessibility checks completed
- Single `<h1>` per page, verified by the build's own guardrail
  (`scripts/verify.mjs`) across all 22 rendered pages including the new one.
- Heading order on the new page is strictly nested (h1 → h2 → h3), no skipped
  levels — the two new section types use h2 for the section and h3 for
  sub-items, matching the existing decision-log pattern.
- External link (Explore live system) carries `rel="noopener noreferrer"`,
  `target="_blank"`, an `external` icon, and visually-hidden "(opens in a new
  tab)" text — same pattern as the existing footer LinkedIn link.
- Focus-visible outlines are inherited from existing global/component styles
  (untouched); no new interactive elements bypass them.
- `prefers-reduced-motion` handling is untouched; no new motion was added
  (no JavaScript was added anywhere in this change).
- Placeholder figures use the site's existing `PlaceholderPlate` pattern,
  which needs no `alt` text (no `<img>` is rendered); real captions
  interpret each placeholder rather than just naming it.
